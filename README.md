# DAJI Project Page

This repository contains the source code for the project page of:

**Before the Body Moves: Learning Anticipatory Joint Intent for Language-Conditioned Humanoid Control**

- Paper: https://arxiv.org/abs/2605.14417
- Code: https://github.com/Hxxxz0/DAJI

## Local Preview

Run a simple static server from the repository root:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://127.0.0.1:8000
```
